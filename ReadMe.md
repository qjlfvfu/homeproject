# Банковский анализатор транзакций #
Проект для анализа и обработки банковских транзакций из различных форматов файлов.

# 📋 Описание проекта #
Банковский анализатор транзакций - это консольное приложение на Python, которое позволяет:

* Загружать транзакции из JSON, CSV и Excel файлов
* 
* Фильтровать операции по статусу, валюте и ключевым словам
* 
* Сортировать транзакции по дате
* 
* Анализировать операции по категориям
* 
* Генерировать статистику по операциям

🚀 Функциональность
Основные возможности:
* Загрузка данных из различных форматов:
* 
* JSON (operations.json)
* 
* CSV (transactions.csv)
* 
* Excel (transactions.xlsx)
* 
* Фильтрация операций по:
* 
* Статусу (EXECUTED, PENDING, CANCELED)
* 
* Валюте (только RUB)
* 
* Ключевым словам в описании
* 
* Сортировка по дате (по возрастанию/убыванию)
* 
* Категоризация операций:
* 
* Переводы
* 
* Оплаты
* 
* Покупки
* 
* Снятия наличных
* 
* Пополнения
* 
* Возвраты
* 
* Статистика по количеству операций в каждой категории
* 
🛠️ Установка и запуск
Требования:
Python 3.8+

Установленные зависимости из requirements.txt

Установка:
bash
# Клонирование репозитория
git clone <repository-url>
cd PythonProject2

# Установка зависимостей
pip install -r requirements.txt
Запуск приложения:
bash
python src/main.py
📊 Формат данных
Пример транзакции:
json
{
  "id": 1,
  "date": "2024-01-15",
  "description": "Перевод между счетами",
  "amount": 1000,
  "currency": "RUB",
  "state": "EXECUTED"
}
Обязательные поля:
date - дата операции

description - описание операции

amount - сумма операции

currency - валюта операции

state - статус операции
