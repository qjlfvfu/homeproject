# homeproject
Проект для поиска, фильтрации и сохранения вакансий с платформы HeadHunter.

## Установка и запуск

Установите зависимости:
` bash
pip install requests `
 ~~А больше нихрена и не надо~~

Запустите приложение:
`bash
python src/main.py`

Функциональность
1. 🔍 Поиск вакансий по ключевым словам на HeadHunter
2. 💰 Фильтрация по зарплате, ключевым словам, опыту работы
3. 📊 Сортировка вакансий по уровню зарплаты
4. 💾 Сохранение результатов в JSON-файл
5. 🎮 Удобный интерфейс для работы через консоль

## Основные классы

### VacancyAPI (api.py)

Абстрактный класс для работы с API вакансий

### HeadHunterAPI (api.py)

Реализация для работы с API HeadHunter

### Vacancy (vacancy.py)

Класс вакансии с методами сравнения по зарплате

### JSONSaver (file_manager.py)
Сохранение и загрузка вакансий в JSON-формате

## Тестирование
Запуск тестов:
`bash
python -m unittest discover tests`
Для проверки тестов рекомендую установить зависимость coverage:
`pip install coverage`
Запустите тест:
`coverage run -m unittest discover tests`
Сделайте красивый файлик с отчетом о покрытии:
`coverage html`
